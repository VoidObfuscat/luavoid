# LuaVoid — Professional Lua Script Hub

> Free, browser-based Lua tools for Roblox developers.

🔗 **Live site:** https://SEU-USUARIO.github.io/luavoid

## Features

- 🛡️ **Obfuscator** — Multi-layer Lua obfuscation, Roblox executor compatible
- 🔓 **Deobfuscator** — Decode string.char(), simplify expressions, remove junk
- 🚀 **Script Hub** — Generate instant `loadstring()` links for Roblox executors
- 🤖 **AI Script Generator** — Describe a script, AI writes the Lua code (OpenAI)
- 🦠 **Anti-Cheat Generator** — Build server-side Roblox anti-cheat systems

## Usage

Open `index.html` in any modern browser — works 100% offline (except AI tab which needs an OpenAI API key).

## AI Tab

Requires a free OpenAI API key from [platform.openai.com](https://platform.openai.com/api-keys).  
Your key is stored only in your browser's `localStorage` — never sent to our servers.
